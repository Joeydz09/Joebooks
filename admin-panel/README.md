# Joebooks Admin — Foundation

هذه مجلدات تأسيس لوحة إدارة Joebooks. الواجهة الحالية **نموذج بصري أولي فقط** وليست لوحة تشغيلية.

## الحالة الحالية
- واجهة عربية RTL متجاوبة بهوية كحلي/فضي/ذهبي.
- أقسام مبدئية: الرئيسية، الكتب، التصنيفات، المحتوى اليومي، صفحات الموقع، الملفات والأغلفة، التحليلات، الإعدادات، سجل العمليات.
- لا يوجد اتصال ببيانات الإنتاج، ولا تسجيل دخول، ولا API، ولا أسرار.
- الأرقام غير متصلة ومتعمدة أن تظهر كشرطات؛ لا تمثل أعداد الموقع.

## التصميم الأمني المستهدف
1. واجهة الإدارة لا تحمل GitHub tokens أو Cloudflare secrets.
2. Worker API خاص يتولى التحقق من جلسة المدير وتوقيع الطلبات.
3. GitHub access محدود بمستودع Joeydz09/Joebooks فقط، وتُحفظ بيانات الاعتماد في أسرار الخادم.
4. القراءة من main أولاً، ثم التعديلات على فرع مستقل.
5. كل تغيير يعرض كمعاينة وdiff قبل إنشاء Pull Request.
6. لا دمج ولا نشر إلى الموقع الرسمي قبل موافقة المدير الصريحة.
7. نسخ احتياطية وسجل تدقيق قبل/بعد كل عملية كتابة.
8. حذف سجل الكتاب لا يحذف كائن R2 تلقائياً.
9. إبقاء تكامل preview/maktabati-integration.js دون تغيير.

## مراحل التنفيذ التالية
- مراجعة نموذج الواجهة.
- اختيار/إعداد Cloudflare Worker وD1 وCloudflare Access أو آلية مصادقة مكافئة.
- ربط GitHub في وضع القراءة فقط واختبار مطابقة البيانات.
- إضافة عمليات الكتب والمحتوى مع تحقق schema ونسخ احتياطي وdiff.
- اختبارات أمنية ووظيفية، ثم طلب مراجعة منفصل قبل أي نشر رسمي.

## ملاحظة النشر
لا تدمج هذا الفرع في main ولا تنشر لوحة الإدارة للعامة. هذا الفرع مخصص للمراجعة والتطوير فقط.
