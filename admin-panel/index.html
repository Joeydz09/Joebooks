آخر النشاطات

تجريبي
سيظهر هنا سجل التعديلات والنشر بعد تفعيل النظام.
لن تُسجّل أي عملية قبل ربط قاعدة البيانات.

قواعد النشر

معاينة التغييرات قبل إرسالها إلى GitHub
إنشاء فرع مستقل وطلب مراجعة Pull Request
عدم الدمج في main إلا بعد موافقتك النهائية
نسخة احتياطية وسجل عمليات لكل نشر

إدارة الكتب

ستُحمّل قائمة الكتب من books.json في وضع القراءة فقط أولاً.
لن يتاح التعديل أو الحذف قبل تفعيل الحماية والنسخ الاحتياطي.

التصنيفات

إدارة التصنيفات وربطها بالكتب — بانتظار مصدر البيانات.

المحتوى اليومي

إدارة الكتاب اليومي والاقتباس اليومي عبر daily-content.json بعد التحقق من بنيته.

صفحات الموقع

إدارة محتوى الصفحات الرئيسية والصفحات الثابتة دون المساس بتكامل Maktabati.

الملفات والأغلفة

فحص الأغلفة وروابط PDF وملفات R2. لن يُحذف أي ملف من R2 تلقائياً عند حذف سجل كتاب.

التحليلات

يمكن إضافة تقارير GoatCounter بعد تحديد صلاحيات القراءة ومصدر البيانات.

إعدادات الموقع واللوحة

إعدادات المدير، تكامل GitHub، Worker، النسخ الاحتياطي وسياسات النشر.
لن تُعرض الأسرار أو مفاتيح API في الواجهة.

سجل العمليات

سجل غير قابل للتعديل يعرض المستخدم والوقت والعملية والملفات المتأثرة ونتيجة النشر.
