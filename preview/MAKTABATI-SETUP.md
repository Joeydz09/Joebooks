# معاينة «مكتبتي» المرتبطة بتيليجرام

هذه ملفات مصدر تجريبية فقط؛ لا يوجد نشر أو اتصال فعلي بقاعدة بيانات حتى الآن.

## الملفات
- `preview/maktabati.html`: واجهة النجوم والتبويبات، تحفظ محليًا للمعاينة فقط.
- `preview/maktabati-worker.js`: مصدر API مقترح للتحقق من Telegram WebApp initData وحفظ معرّفات الكتب.
- `preview/maktabati-schema.sql`: مخطط جدول مستقل للمكتبة الشخصية.

## قبل أي تشغيل
1. أنشئ قاعدة D1 مخصصة لهذا المشروع ولا تستخدم قاعدة Writers Corner الحالية.
2. اربطها باسم `DB` في Worker مستقل.
3. خزّن رمز البوت في secret باسم `BOT_TOKEN` على الخادم فقط؛ لا تضعه في HTML أو Git.
4. راجع نطاقات CORS ومدة صلاحية initData وسياسة الخصوصية قبل النشر.
5. عدّل الواجهة لتقرأ `Telegram.WebApp.initData` وتستدعي API؛ لا تثق بمعرّف مستخدم يرسله العميل دون تحقق الخادم.
6. اختبر الإضافة والإزالة واسترجاع القائمة بحسابات تجريبية قبل أي ربط بالموقع الرسمي.

## API المقترح
- `GET /api/library` — استرجاع أرقام الكتب للمستخدم الموثّق.
- `POST /api/library` مع `{"book_id": 2059}` — إضافة كتاب.
- `DELETE /api/library` مع `{"book_id": 2059}` — إزالة كتاب.

لا تنشر هذه الملفات ولا تنشئ/تغيّر موارد Cloudflare قبل موافقة صاحب المشروع.
